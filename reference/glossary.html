Rust Glossary

The compressed language of this workspace. A term lands here only once it has been used correctly — in the user's own code or recalled from memory — never on first introduction.

Terms

Cargo: Rust's build tool and package manager: it scaffolds, compiles, tests, lints, and fetches dependencies. _Evidence_: two working Cargo projects (guessing_game/, playground/); Lesson 0001.

Manifest (Cargo.toml): The file declaring a package's name, edition, and dependencies; the one project file the developer hand-edits. _Evidence_: both workspace projects carry edited manifests; Lesson 0001.

Lockfile (Cargo.lock): The file pinning the exact resolved versions of every dependency; owned by Cargo, committed for binaries, never hand-edited. _Evidence_: Lesson 0001 quiz, answered correctly.

Macro (the ! suffix): A compile-time code expansion, distinct from a function call; the trailing ! is the visual marker when reading code. _Evidence_: Lesson 0001 quiz, answered correctly.
