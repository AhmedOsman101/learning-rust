# Mission: Rust

## Why
Ship a real CLI tool built with clap, written in idiomatic Rust that passes Clippy and reads like experienced Rust code — and be able to open an unfamiliar Rust codebase and explain where it starts, how modules fit, and how data flows through it.

## Success looks like
- Write idiomatic Rust: passes Clippy, follows the Rust API Guidelines, looks like experienced Rust code
- Read an unfamiliar Rust codebase and explain it: entry point, module tree, key types and traits, data flow
- Build a CLI tool with clap as the first tangible target

## Constraints
- Experienced programmer (5+ years TS/JS/PHP/Bash), new to ownership, borrowing, lifetimes, systems thinking
- Finished Rust Book chapters 1–3 about a year ago; restarting from chapter 4 (ownership)
- Bridge Result/Option from `lib-result` (TypeScript) where it helps
- One tightly scoped lesson at a time; compiler errors and retrieval practice over lectures

## Out of scope
- TUI and desktop apps (come after the CLI)
- Unsafe Rust / advanced systems topics until the foundations stick
