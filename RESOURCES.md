# Rust Resources

## Knowledge

- [The Rust Programming Language (the Book) — local HTML](file:///home/othman/.local/share/rustup/toolchains/stable-x86_64-unknown-linux-gnu/share/doc/rust/html/book/)
  The primary source for this workspace. Covers the full arc: ownership through CLI project. Use for: every lesson's grounding and primary reading link. (Online mirror: https://doc.rust-lang.org/book/)
- [Rust By Example — local HTML](file:///home/othman/.local/share/rustup/toolchains/stable-x86_64-unknown-linux-gnu/share/doc/rust/html/rust-by-example/)
  Runnable examples per concept. Use for: quick second angles when the Book's explanation doesn't click.
- [Standard library docs — local HTML](file:///home/othman/.local/share/rustup/toolchains/stable-x86_64-unknown-linux-gnu/share/doc/rust/html/std/index.html)
  Authoritative API reference. Use for: exact signatures of `Option`, `Result`, `String`/`str`, iterators, collections.
- [Rust Reference — local HTML](file:///home/othman/.local/share/rustup/toolchains/stable-x86_64-unknown-linux-gnu/share/doc/rust/html/reference/index.html)
  Precise language semantics. Use for: settling arguments about what the compiler really guarantees.
- [Clippy lint list](https://rust-lang.github.io/rust-clippy/master/)
  The idiom enforcer. Use for: stage 6 idiom refinement and justifying "why is this unidiomatic?"
- [Rust API Guidelines](https://rust-lang.github.io/api-guidelines/)
  Naming and API design conventions. Use for: making code look like experienced Rust.
- [The Rustonomicon — local HTML](file:///home/othman/.local/share/rustup/toolchains/stable-x86_64-unknown-linux-gnu/share/doc/rust/html/nomicon/index.html)
  Unsafe Rust. Use for: only if a lesson genuinely needs it; out of scope otherwise.
